# README
Application developed in this "project" is envisioned to continuously evolve into a alternative to project management apps like Trello or Microsoft Planner.

## Technical specifications:
* Ruby @ v. 3.1.2
* Rails @ v. 7.1.3
* Database
    - Dev => SQLite3 @ v.
    - Deployment => PostgreSQL (tbd)
